## Scope and notation

This manifest maps the offering rows selected by ENG-413 to the cited first-party evidence. It does not create facts by expanding code sequences, regional ranges, family names, or colour matrices.

- `None verified` means the source verifies the offering but does not publish a distinct offering-level maker identifier. A stable refill model is not repeated as an offering identifier.
- `No assertion` means the evidence proves the offering existed or was introduced but does not prove `current`, `discontinued`, or `historical` availability in a controlled market.
- `Unknown` market is preserved when a manufacturer technical page does not state a country, region, or worldwide availability scope. It must not be converted to `GLOBAL` from page language alone.
- Grouped colour rows share the source, market, lifecycle conclusion, and identifier treatment shown in that row. Every listed code is transcribed from the source; no omitted code may be reconstructed from the pattern.
